# CAFE project website

Independent research project page for Closed-Loop Autonomous Task Formulation and Execution without Explicit Task Input.

Site: https://mingjia2005.github.io/CAFE-Closed-Loop-Autonomous-Task-Formulation-and-Execution-without-Explicit-Task-Input/

## Preview

Run `python -m http.server 8765` from this directory and open `http://localhost:8765`.

## GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save. The `.nojekyll` file serves the static site without a Jekyll build.

## Figures

All five user-supplied PDFs are included. Both pages of the ablation PDF are displayed. WebP figures are rendered from their corresponding PDFs; numerical baseline data is retained from the existing project page. The kitchen cover is an illustrative reconstruction.

The site uses local Manrope and Source Serif 4 fonts, responsive layouts, accessible tabs and a keyboard-accessible full-resolution figure viewer.
